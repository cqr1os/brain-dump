Back up your notes

Your notes get copied to a private repo on your GitHub called brain-dump-notes. Only you can see it. This app needs a key that can write to that one repo and nothing else.

  1. Open GitHub's key page and sign in if it asks.
  2. Under Repository access, pick Only select repositories and choose brain-dump-notes.
  3. Under Permissions, set Contents to Read and write.
  4. Set Expiration to No expiration if it's there, otherwise the longest one. Tap Generate token and copy it.
